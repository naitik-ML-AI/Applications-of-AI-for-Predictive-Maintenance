# Applications-of-AI-for-Predictive-Maintenance

An AI-based predictive maintenance project that uses machine learning and deep learning techniques to identify potential failures, analyze time-series behavior, and detect abnormal patterns before they lead to system downtime.

Features
XGBoost for failure prediction
CPU, GPU & RAPIDS performance comparison
LSTM for time-series prediction
CNN-LSTM for sequence-based modeling
LSTM & Conv1D Autoencoders for anomaly detection
ROC/AUC analysis for model evaluation
Bayesian Hyperparameter Optimization
Remaining Useful Life (RUL) prediction


Project Workflow
Raw Sensor Data
      ↓
Data Cleaning & Preprocessing
      ↓
XGBoost Failure Prediction
      ↓
LSTM / CNN-LSTM Time-Series Analysis
      ↓
RUL Prediction
      ↓
Autoencoder Anomaly Detection
      ↓
Performance Evaluation

 Objective
The primary objective is to apply different AI techniques to predictive maintenance so that potential failures and abnormal behavior can be identified before they result in unexpected downtime.
